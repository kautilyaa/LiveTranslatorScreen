This documentation provides details about all available API endpoints, request/response formats, and example usage for the Manga Translator API.

API Overview

The Manga Translator API provides a comprehensive set of endpoints for processing manga images, performing OCR, inpainting, and translation. The API follows a modular design with plugin architecture for different providers.

Base URL

http://localhost:5000/api

Available Endpoints

  • /process - Process manga image (end-to-end pipeline) POST
  • /ocr - Perform OCR on an image POST
  • /translate - Translate text POST
  • /inpaint - Inpaint an image with mask POST
  • /detect - Detect text regions in an image POST
  • /providers - List available providers GET

Authentication

The API currently does not require authentication for local development. For cloud-based OCR and translation services, API keys must be configured as environment variables.

Environment Variables

API Endpoints

POST/process

Process a manga image with text detection, OCR, inpainting, and translation.

Request Parameters

Parameter Type Description Required
image string Base64-encoded image data Yes
ocr_provider string OCR provider name (tesseract, easyocr, azure, aws) No
inpainting_model string Inpainting model name (lama, stable_diffusion) No
translator string Translator provider name (huggingface, llm, ollama, google, deepl) No
source_language string Source language code (ja, ko, en, etc.) No
target_language string Target language code (en, ja, ko, etc.) No

Response

Field Type Description
processed_image string Base64-encoded processed image with inpainted text regions
detected_texts array Array of detected text objects with original and translated text
processing_time object Timing information for each processing step

Example

{
  "image": "base64_encoded_image_data",
  "ocr_provider": "tesseract",
  "inpainting_model": "lama",
  "translator": "huggingface",
  "source_language": "ja",
  "target_language": "en"
}
{
  "processed_image": "base64_encoded_processed_image",
  "detected_texts": [
    {
      "text": "こんにちは世界",
      "translated_text": "Hello world",
      "bounding_box": [100, 200, 150, 50],
      "confidence": 0.95
    }
  ],
  "processing_time": {
    "detection": 0.2,
    "ocr": 0.3,
    "inpainting": 0.8,
    "translation": 0.4,
    "total": 1.7
  }
}

POST/ocr

Perform OCR on an image with specified provider.

Request Parameters

Parameter Type Description Required
image string Base64-encoded image data Yes
provider string OCR provider name (tesseract, easyocr, azure, aws) No
language string Language code for OCR (ja, ko, en, etc.) No

Response

Field Type Description

  "provider": "tesseract",

      "text": "こんにちは世界",

}

GET/providers

Get all available providers for OCR, translation, and inpainting.

Response

Field Type Description
ocr array List of available OCR providers
inpainting array List of available inpainting models
translation array List of available translators

Example Response

{
  "ocr": ["tesseract", "easyocr", "azure", "aws"],
  "inpainting": ["lama", "stable_diffusion"],
  "translation": ["huggingface", "llm", "ollama", "google", "deepl"]
}

Error Handling

The API returns standard HTTP status codes and a JSON response with an error message when an error occurs.

Error Response Format

{
  "error": "Error message describing what went wrong"
}

Common Error Codes

Status Code Description
400 Bad Request - Missing required parameters or invalid data
404 Not Found - Endpoint not found
500 Internal Server Error - Server-side error occurred

Client Library Examples

Python Example

import requests
import base64
from PIL import Image
import io

# Load image file
with open('manga_image.jpg', 'rb') as image_file:
    image_data = base64.b64encode(image_file.read()).decode('utf-8')

# Call process endpoint
url = 'http://localhost:5000/api/process'
payload = {
    'image': image_data,
    'ocr_provider': 'tesseract',
    'inpainting_model': 'lama',
    'translator': 'huggingface',
    'source_language': 'ja',
    'target_language': 'en'
}

response = requests.post(url, json=payload)
result = response.json()

# Display results
if 'error' not in result:
    # Convert base64 processed image back to image
    processed_image_data = base64.b64decode(result['processed_image'])
    processed_image = Image.open(io.BytesIO(processed_image_data))
    processed_image.show()
    
    # Print detected texts
    for text in result['detected_texts']:
        print(f"Original: {text['text']}")
        print(f"Translated: {text['translated_text']}")
        print("---")
else:
    print(f"Error: {result['error']}")

JavaScript Example

// Function to process a manga image
async function processImage(imageFile) {
  // Convert file to base64
  const base64Image = await fileToBase64(imageFile);
  
  // Call process endpoint
  const response = await fetch('http://localhost:5000/api/process', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      image: base64Image,
      ocr_provider: 'tesseract',
      inpainting_model: 'lama',
      translator: 'huggingface',
      source_language: 'ja',
      target_language: 'en'
    })
  });
  
  // Parse response
  const result = await response.json();
  
  if (!result.error) {
    // Process successful
    console.log('Processing successful!');
    console.log('Detected texts:', result.detected_texts);
    
    // Display processed image
    const processedImageElement = document.getElementById('processed-image');
    processedImageElement.src = `data:image/jpeg;base64,${result.processed_image}`;
  } else {
    // Handle error
    console.error('Error:', result.error);
  }
}

// Helper function to convert file to base64
function fileToBase64(file) {
  return new Promise((resolve, reject) => {
    const reader = new FileReader();
    reader.readAsDataURL(file);
    reader.onload = () => {
      // Remove data URL prefix (e.g., "data:image/jpeg;base64,")
      const base64String = reader.result.split(',')[1];
      resolve(base64String);
    };
    reader.onerror = error => reject(error);
  });
}
